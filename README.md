# 苍穹外卖 sky-take-out

前后端分离的外卖点餐系统，包含管理端（Web 后台）与用户端（微信小程序）。

## 技术栈

- **后端**：Spring Boot、MyBatis、MySQL、Redis、Druid、PageHelper、JWT、WebSocket、Spring Task、POI、阿里云 OSS、微信支付、百度地图 API
- **管理端**：Vue.js、ElementUI、ECharts、Nginx
- **用户端**：微信小程序（uni-app + uni-ui）

## 功能

- **管理端**：员工、分类、菜品、套餐、订单管理，营业数据统计与报表导出
- **用户端**：浏览点餐、购物车、地址簿、下单支付、历史订单、催单
